# LRU/LFU Cache with Persistent Backing Store

**CSCE 2200: Applied Data Structures — Term Project, Fall 2026 (AUC)**
Project idea: **A6 — LRU/LFU Cache with Persistent Backing Store**

A cache simulator built on hand-written data structures (no STL containers). It
implements several eviction policies on top of a disk-based backing store, then
compares them under sequential, random, and Zipfian workloads.

## Policies and structures

| Component | Data structure(s) | Target complexity |
|---|---|---|
| LRU | Hash table + doubly linked list | O(1) get/put |
| LFU (heap) | Hash table + indexed min-heap | O(log n) |
| LFU (O(1)) | Hash table + list of frequency nodes, each holding a list of keys | O(1) |
| CLOCK | Circular array + reference bits + hash table | O(1) amortized |
| Backing store | Paged file on disk with an on-disk hash index | O(1) expected page I/Os |

See `docs/PLAN.md` for the full design and `docs/INTERFACES.md` for the
agreed API contracts.

## Build and run

Requires `g++` with C++17 support and `make`.

```
make            # build the CLI  -> build/cachesim   (needs src/main.cpp)
make test       # build and run every tests/test_*.cpp with sanitizers
make check-stl  # fail if a forbidden STL header is included in include/, src/, benchmarks/
make clean
```
